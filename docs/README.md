## Documentation Structure

This documentation is organized to help both new developers and experienced contributors understand the codebase:

- **Getting Started**: For new developers joining the project
- **Architecture**: High-level understanding of the application structure
- **Features**: Detailed documentation of each major feature
- **Database**: Schema and data management information
- **API**: Technical reference for developers
- **Frontend**: Client-side implementation details
- **Testing**: Testing approach and guidelines
- **Deployment**: Production deployment information
- **Development**: Guidelines for contributors

## How to Use This Documentation

1. **New Developers**: Start with [Getting Started](./getting-started.md) and [Architecture Overview](./architecture.md)
2. **Feature Implementation**: Refer to the specific [Features](./features.md) documentation
3. **API Integration**: Use the [API Documentation](./api.md) for technical reference
4. **Contributors**: Follow the [Development Guidelines](./development.md)
